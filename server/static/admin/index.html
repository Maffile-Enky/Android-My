APK 上传说明

APK 文件需要手动上传到服务器的 static/files/ 目录。
上传命令：scp app-v1.1.0.apk root@server:/opt/toolbox-server/static/files/
然后在上方填写 APK 地址为 /files/app-v1.1.0.apk
